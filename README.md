# The K-shaped economy

An interactive industry transmission map and a standalone research prompt.

- [Open the interactive map](https://fasinisterra.github.io/k-shaped-economy/)
- [Read or save the research prompt](https://fasinisterra.github.io/k-shaped-economy/claude-code-research-prompt.txt)
- [Original HTML resource](K-Shaped-Economy-Transmission-Map.html)

The map contains 109 themes, 60 listed companies, and 212 source records. Research cutoff: October 4, 2026. Research credit: Dave Wang, as shown in the original map.

The original resource contents are preserved. `index.html` is an identical copy of `K-Shaped-Economy-Transmission-Map.html` for the public site. The map includes local JSON, CSV, and Markdown downloads.
